# 背景に近い券面の追加改善（2026-10-23）

## 取り扱い

利用者の指定に従い、元スキャンの文字・顔・内容の解析、画像表示、検出器への投入は行わない。
確認はヘッダの寸法・DPI、画像外周4px、および利用者が指定した券面範囲の
四辺から内外20px以内の2px幅の帯の色コード集計に限定する。
元画像・画像断片・個別の画素列は保存・送信・テスト利用しない。

## 方針

外周の暗い帯と明るい背景が混在すると、外周全体の色のばらつきを使う閾値が、
淡い券面の差を超えてしまう可能性がある。前回の補完閾値も本閾値の半分であり、
背景のばらつきが大きいほど一緒に上がってしまう。

四辺の背景色・ばらつきを別々に推定する補完探索を追加し、安定した辺の背景色を
使って小さな色差も調べる。補完候補は従来と同じDPI・公的寸法の照合を通す。
印刷部分の寸法を規格値へ引き伸ばして補う方法は採らず、外周の根拠が得られる候補を使う。

背景が緩やかに変わる場合にも対応するため、近傍の両側の色差から境界を探す補完パスも設ける。
このパスは細い輪郭を消さずにつなぎ、閉じた輪郭の内側も調べる。補完候補が画像端2辺以上に
接する場合は、背景の濃淡やスキャナ枠の可能性が高いため採用しない。

補完パスはRGBを平滑化し、浮動小数点Labで計算する。8bitのLabでは小さな色差が量子化で
失われるため、浮動小数点で0.75〜の小さな色差を調べる。各パスのマスクと輪郭はその都度解放する。
通常パスと規格外サイズの扱いは維持する。

## 検証方針

色だけを参考にコードで生成した合成スキャンで、暗い外周帯と背景に近い券面、
傾き、背景のノイズ・濃淡、カードなし、複数候補を検証する。
元スキャンでの検出成功は、利用者が新しい試用版で確認するまで未確認として扱う。

追加した合成ケースは、暗い外周帯、±25度の傾き、緩やかな照明変化と微小ノイズ、
スキャナの暗い帯の近くに置かれた券面（2位置）、カードなし、離れた2枚の券面。
券面の幅・高さは既知寸法から25px以内、中心は15px以内であることを検証する。
従来処理で暗い外周帯を含む3ケースが検出できないことも、変更前に確認した。

元画像の境界付近で取得した色は小領域の集計だけであり、正確な券面境界の判定や内容の解析は行っていない。
確認画面での手動調整は `docs/manual-editor.md` を参照。
