# 切り出し位置の手動調整

## 操作

確認画面のサムネイルを押すと編集画面を開く。要確認・検出失敗・規格寸法不一致の画像には、
サムネイルを押して位置を調整する案内を出す。読み込み不能・上限超過の画像は編集対象にしない。

元スキャンの縮小画像上で券面の枠をドラッグ、または移動先をクリックして中心を変更する。
拡大表示・矢印キー・中心座標入力で微調整でき、傾きは±90度で調整する。
券面サイズは選択中の種別の規格寸法（身分証85.60×53.98mm、旅券見開き176×125mm）に固定する。
青い券面枠と、余白を含む出力用の枠を表示し、切り出し結果もその場で確認できる。

「調整を反映」でサムネイル・券面サイズ・出力位置を更新し、手動調整済みと表示する。
編集を破棄した場合は変更しない。検出失敗も手動調整により出力対象に戻せる。
券面枠が元画像の外にはみ出す指定は受け付けない。規格外寸法の手動指定は今回の対象外。
種別を変更した場合は、その種別で再度編集して確認する。

## データと安全性

元画像は変更しない。編集用の全体プレビューは長辺1600px以下のWebPとしてメモリ内にだけ保持する。
rendererへ任意のファイルパスは受け渡さず、解析済みIDに対応する入力だけをworkerで読み込む。
手動指定の座標・角度はmainからworker側でも検査し、出力と同じ切り出し処理へ渡す。
ジョブを中止・再解析すると手動調整も破棄する。画像・個人情報・座標をログに保存しない。

開発時の検証には合成画像だけを使う。利用者の元スキャンは、別途許可された境界付近の
色コード集計以外には使用しない。

## 確認手順

- `npm run verify`: 位置・角度・画像外指定の拒否、編集可能な画像の判定、検出失敗からの復帰、
  破棄時の不変、入力ファイルの不変、サムネイルとA4出力の一致を自動テストする。
- `npm run test:editor`: 合成画像で、ビルド済みの画面・preload・workerを使用し、案内表示、
  サムネイルからの起動、クリック移動、ドラッグ、Shift+矢印キー、破棄、範囲外の反映禁止、
  保存、再表示、A4出力までを確認する。mainのIPCハンドラは検証用のハンドラに差し替えている。
  生成物は `.tmp/editor-check/` に限る。利用者の元スキャンは使わない。
- `npm run package`: Windows x64のポータブル版とインストーラを作成する。

試用版 `release/IdentificationIntegratorOnA4 0.1.2.exe` で再解析し、サムネイルから位置を調整する。
インストーラによるインストール操作、利用者の実画像での新しい検出結果は未確認。

2026-10-23の確認結果: lint・型検査・14ファイル225テスト、編集画面の操作試験、Windowsの
ポータブル版・NSISインストーラ生成が成功。最小900×600の画面と1/2/4倍表示でも編集を確認した。
